# Las Dos Doncellas · Frontend

Tienda online y panel CMS en React 19 + Tailwind + Shadcn UI.

```bash
yarn install
echo "REACT_APP_BACKEND_URL=http://localhost:8001" > .env
yarn start      # desarrollo
yarn build      # producción (carpeta build/)
```
